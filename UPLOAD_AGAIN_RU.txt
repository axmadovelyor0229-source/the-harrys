ПОЛНАЯ ПЕРЕЗАГРУЗКА THE HARRY'S

1. Удали старые файлы из репозитория GitHub (или создай новый репозиторий).
2. Распакуй этот ZIP.
3. Загрузи ВСЁ содержимое папки в корень репозитория.
4. Не загружай .env с настоящими паролями/ключами.
5. На GitHub: Settings -> Pages -> Source: GitHub Actions.
6. После Push открой Actions и дождись зелёной галочки.
7. GitHub Pages использует папку frontend.
8. Для GitHub Pages вход работает в DEMO-режиме; на VPS будет использоваться backend.
