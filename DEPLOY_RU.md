# Запуск the harry's на сервере

## Что уже готово
Сайт V19, backend API, PostgreSQL, серверная авторизация, хеширование паролей, централизованное сохранение состояния, Docker Compose, Nginx, backup/restore и заготовка iikoCloud.

## Что понадобится от владельца сервера
- VPS с Ubuntu 24.04 (для старта достаточно 2 GB RAM; лучше 2 vCPU / 2–4 GB RAM).
- IP сервера и SSH-доступ.
- Домен, если нужен красивый адрес и HTTPS.
- iikoCloud API Login / разрешение на API и ID организаций для реальной синхронизации.

## Порядок запуска
1. Загрузить папку проекта на сервер, например `/opt/the-harrys`.
2. Выполнить `sudo ./scripts/bootstrap-ubuntu.sh`.
3. Скопировать `.env.example` в `.env`.
4. Поставить длинные случайные значения `POSTGRES_PASSWORD` и `JWT_SECRET`.
5. Добавить `IIKO_API_LOGIN`, когда он будет получен/разрешён в iikoCloud.
6. Запустить `./scripts/deploy.sh`.
7. Проверить `http://IP/api/health` и затем сам сайт.
8. После проверки подключить домен и HTTPS.
9. Сразу сменить временные пароли пользователей.
10. Поставить ежедневный cron на `scripts/backup.sh` и копирование backup во второе хранилище.

## Обновления после запуска
Обновления не требуют покупать новый сервер. Перед обновлением делается backup базы, затем обновляется код и выполняется `./scripts/deploy.sh`. PostgreSQL хранится в отдельном Docker volume, поэтому обычное обновление frontend/backend не стирает бизнес-данные.
